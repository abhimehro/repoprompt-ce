## 2025-02-14 - Time-of-Check-to-Time-of-Use (TOCTOU) vulnerability
**Vulnerability:** A TOCTOU race condition exists in file writes. Several components (e.g. `MCPTerminalRecordStore`, `MCPConfigExportService`, `MCPIntegrationHelper`, `GitWorktreeMergePreviewPublisher`, `DeviceIdentity`) write content to a file (sometimes with `.atomic`) and then subsequently call `FileManager.setAttributes` to lock down permissions (e.g., 0o600 or 0o400).
**Learning:** During the small window between `.write()` completing and `setAttributes()` applying, an attacker or another process can access or modify the file (which often contains sensitive configurations or identity material). This exists because standard Swift Data/String writes do not provide atomic permission setting during creation.
**Prevention:** Always create files directly with the required secure POSIX permissions (using `FileManager.createFile(atPath:contents:attributes:)` on a temporary file) before moving them into place, preventing the TOCTOU window.
