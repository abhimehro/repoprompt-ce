## 2025-07-07 - Add accessibility labels to icon-only buttons
**Learning:** In SwiftUI, icon-only interactive elements and those with custom interactions/tooltips require explicit `.accessibilityLabel` modifiers to be legible to VoiceOver and other screen readers. Blindly applying `.accessibilityLabel` to buttons containing text like `Text("Check Recommendations")` overrides the text and provides the exact same information, which is redundant but correct if custom labels are provided. But for icon-only buttons like the notifications bell or settings cog, the `accessibilityLabel` is vital. Also `hoverTooltip` doesn't automatically generate an `accessibilityLabel`.
**Action:** When creating icon-only buttons, always ensure an `accessibilityLabel` is provided alongside any `hoverTooltip`.
